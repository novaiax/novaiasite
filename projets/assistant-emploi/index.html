Chercher selon mon parcours

Au printemps 2026, j’ai exploré le travail salarié dans la vente pour apprendre le commercial dans un cadre structuré, tout en gardant NovaiaWeb. J’ai réorienté un ancien agent de recherche de missions de développement vers des postes commerciaux. La zone, le type de contrat, l’expérience demandée et la proximité avec le web ou la tech devaient aider à faire ressortir les offres auxquelles je pouvais réellement candidater.

Garder une continuité

Le système rassemble les offres, les identifie pour éviter de les recréer et les fait avancer dans un tableau de suivi. Une candidature déjà traitée ne doit pas revenir comme si elle était nouvelle. Ce travail m’a fait pratiquer l’ingestion, les identifiants stables et la déduplication sur un problème qui avait une utilité immédiate pour moi.

Une étape, pas ma direction actuelle

Cette exploration fait partie de mon parcours. Aujourd’hui, ma priorité reste de développer NovaiaWeb. Je conserve ce projet comme une expérimentation concrète de l’automatisation : partir d’une tâche répétitive, la structurer et garder la main sur les décisions.
