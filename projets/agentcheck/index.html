Regarder le site autrement

J’ai développé AgentCheck pour examiner les catalogues et les parcours e-commerce du point de vue d’un agent IA. Les informations doivent être compréhensibles au-delà de ce qui se voit à l’écran.

Rendre les points à améliorer visibles

Le scanner examine la structure du catalogue, l’accès aux données produits, les API et le parcours de commande. Il réunit ces constats dans un score accompagné des points relevés, pour donner une base à un audit plus précis.

Relier la veille à la création web

Ce projet réunit deux choses qui m’intéressent : les nouveaux usages de l’IA et la manière de construire des sites utiles. Il me permet d’explorer une évolution du commerce en ligne à travers un outil concret.
