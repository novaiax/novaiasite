Des bases en informatique mises en pratique dans dix séries d’exercices et un projet personnel.

Dans l’atelier

Apprendre les bases, puis construire mon propre projet.

Une pyramide, du texte, des images

Les exercices m’ont fait travailler sur des problèmes précis : construire une pyramide dans le terminal, rendre la monnaie, vérifier un numéro avec l’algorithme de Luhn ou calculer la lisibilité d’un texte. Les filtres d’images m’ont aussi amené à manipuler les pixels et les couleurs.

Un indice, pas la solution

Quand je bloquais, je demandais souvent un indice minime plutôt que le code complet. Je voulais réussir à retrouver la logique et pouvoir expliquer ce que j’avais écrit. Comprendre un exercice par moi-même faisait partie de ce que je venais chercher dans ce cours.

Faire entrer le web

Avec Birthdays et Finance, j’ai travaillé sur Flask, les formulaires, les comptes utilisateurs et les bases SQLite. Le projet Homepage m’a permis de faire un site personnel, avec notamment un minuteur Pomodoro. Les exercices ne restaient plus seulement dans le terminal.

Un projet que je voulais garder

Pour le projet final, j’ai choisi NovaLog, un journal de discipline quotidien. Il réunissait une connexion, des catégories de tâches, un suivi et un historique. L’idée me plaisait parce que ce journal pouvait réellement me servir après le cours.

Mon certificat CS50

J’ai obtenu mon certificat vérifié pour CS50x, le cours d’introduction à l’informatique de Harvard. Il a été délivré le 14 janvier 2026. Le document et le lien de vérification sont accessibles ici, avec le code de mes exercices et de mon projet final.
